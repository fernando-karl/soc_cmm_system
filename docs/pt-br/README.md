# Documentação em Português (pt-BR) — SOC CMM Assessment System

Bem-vindo à documentação em português do SOC CMM Assessment System, uma
aplicação construída com FastAPI e SQLite para conduzir avaliações de
maturidade de SOC (Security Operations Center) com base no framework
**SOC-CMM®** de Rob van Os.
