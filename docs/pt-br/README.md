# Documentação em Português (pt-BR) - SOC CMM Assessment System

Bem-vindo à documentação em Português do Brasil do SOC CMM Assessment System, uma aplicação construída com FastAPI e SQLite para conduzir avaliações de maturidade de SOC (Security Operations Center) baseadas no modelo CMM.
