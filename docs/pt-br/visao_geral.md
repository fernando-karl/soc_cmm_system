# Visão Geral

O SOC CMM Assessment System permite realizar avaliações de maturidade de SOC (Security Operations Center) com uma experiência completa de ponta a ponta:

- Criação e gestão de clientes
- Criação de avaliações por cliente
- Questionário por domínios/aspectos do SOC CMM
- Cálculo automático de pontuações e visualização em gráfico radar
- Histórico de avaliações e progresso ao longo do tempo
- Autenticação de usuários (JWT + cookies) e isolamento de dados por usuário
- Recursos administrativos (dashboard e gestão de usuários)
- Suporte a idiomas (EN/PT-BR)
- Integração via MCP para uso com modelos de IA

Porta padrão: `8400`. Para executar localmente: `python main.py` (após instalar dependências).
