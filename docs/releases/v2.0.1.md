## Security

`.gitignore` did not cover every database backup this project's own scripts
write. `scripts/migrate_bilingual.py` writes `<db>.bak_<timestamp>`, and no rule
matched it:

| Pattern | Why it missed |
| --- | --- |
| `*.db` | a suffix after `.db` means the name no longer ends in `.db` |
| `*.db.backup_*` | the name is `.bak_`, not `.backup_` |
| `*.bak` | the name ends in `.bak_<timestamp>`, not `.bak` |

So a live SQLite database holding users, bcrypt password hashes and customer
records could be staged by `git add -A`. `*.db-wal` and `*.db-shm` were
uncovered too.

Every backup name the repository generates is now ignored, each traced to the
script that writes it:

| Script | Name written |
| --- | --- |
| `scripts/migrate_to_auth.py` | `<db>.backup_<timestamp>` |
| `scripts/run_admin_migration.py` | `<db>.backup_admin_<timestamp>` |
| `scripts/migrate_bilingual.py` | `<db>.bak_<timestamp>` |
| `scripts/legacy/create_translated_database_safe.py` | `soc_cmm_backup_<timestamp>.db` |

`.cursor/`, `.vscode/` and `.idea/` are ignored as well.

A broad ignore rule can do as much damage as the hole it closes, so the tests
check both directions: every generated name is ignored, the dataset, schema and
example files the repository tracks are not, no tracked file in the whole index
became ignored, and no database is tracked at all.

## Releasing

`docs/releases/README.md` now documents the release procedure. `git tag -a vX.Y.Z`
with no commit argument tags whatever `HEAD` happens to be — and because this
project's history was rewritten once to purge committed databases, a pre-rewrite
clone shares **no common ancestor** with `main`. Tagging such a clone and
pushing re-uploads that purged history, databases included.

The procedure verifies the SHA before tagging, passes it to `git tag`
explicitly, and records the recovery: delete the remote tag to make the objects
unreachable, then ask GitHub Support to purge the cached views, because
unreachable objects stay fetchable by SHA until garbage collection.

**If you have a clone from before the rewrite, do not tag or push it.**
