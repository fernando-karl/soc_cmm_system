# English Documentation — SOC CMM Assessment System

Welcome to the English documentation for the SOC CMM Assessment System, a
FastAPI + SQLite application for running SOC (Security Operations Center)
maturity assessments based on the **SOC-CMM®** framework by Rob van Os.
