1. Introdução

O que é o SOC CMM?

O Modelo de Maturidade de Capacidades do Centro de Operações de Segurança (SOC CMM) é um framework abrangente projetado para avaliar e melhorar a maturidade dos Centros de Operações de Segurança em organizações. Ele fornece uma abordagem estruturada para avaliar as capacidades do SOC e identificar áreas para melhoria.

Gestão de Clientes

Criar e gerenciar múltiplos clientes/organizações

Avaliação Passo a Passo

Questionário guiado dividido em seções gerenciáveis

Avaliação de Maturidade

Avaliação em escala de maturidade de 5 níveis

Resultados Visuais

Gráficos de radar interativos e acompanhamento de progresso

2. Começando

1

Gestão de Clientes

Navegue até a página Clientes e clique em "Adicionar Cliente" para criar uma nova organização. Preencha os detalhes do cliente incluindo nome, email e organização.

Dica: Você pode criar múltiplos clientes para gerenciar avaliações para diferentes organizações.
2

Criar Avaliação

Na lista de clientes, clique em "Nova Avaliação" para iniciar uma nova avaliação. O sistema criará uma nova avaliação e redirecionará você para o questionário.

3

Completar Avaliação

Siga o processo guiado através de todos os domínios e aspectos. Responda às perguntas usando a escala de maturidade de 5 níveis e acompanhe seu progresso.

3. Fluxo de Avaliação

Seleção de Domínio

Comece com o domínio Business e trabalhe através de cada domínio sistematicamente. Use a barra de progresso e indicador de etapa para acompanhar sua posição.

Seleção de Aspecto

Dentro de cada domínio, selecione aspectos específicos para avaliar. Cada aspecto contém perguntas relacionadas que avaliam diferentes capacidades.

Responder Perguntas

Responda todas as perguntas em cada aspecto usando a escala de maturidade de 5 níveis. Complete todos os aspectos em um domínio antes de prosseguir para o próximo.

Ver Resultados

Após completar todos os domínios, visualize seus resultados incluindo gráficos de radar, pontuações por domínio e detalhamentos específicos.

Dicas para Avaliação

  • Salvar Progresso: Seu progresso é salvo automaticamente conforme você completa os aspectos
  • Retomar Depois: Você pode retornar a avaliações incompletas a qualquer momento
  • Revisar Respostas: Use o botão "Voltar aos Aspectos" para revisar e modificar respostas
  • Completar Tudo: Certifique-se de que todas as perguntas em um aspecto sejam respondidas antes de prosseguir

5. Entendendo os Resultados

Gráfico de Radar

O gráfico de radar fornece uma representação visual da maturidade do seu SOC em todos os seis domínios. Cada eixo representa um domínio, e a forma mostra seus pontos fortes relativos e áreas para melhoria.

Como Interpretar:

  • Área maior: Maior maturidade geral
  • Forma equilibrada: Desenvolvimento uniforme entre domínios
  • Picos: Áreas de força
  • Vales: Áreas que precisam de melhoria

Detalhamento por Domínio

Pontuações detalhadas para cada domínio mostram seu nível de maturidade e fornecem insights específicos sobre as capacidades do seu SOC.

Detalhes dos Aspectos

Explore aspectos específicos dentro de cada domínio para entender o desempenho detalhado e identificar oportunidades específicas de melhoria.

Interpretando Seus Resultados

Nível 1-2 (Inicial/Em Desenvolvimento)

Foque em estabelecer processos básicos e documentação. Priorize capacidades fundamentais.

Nível 3 (Definido)

Boa base estabelecida. Foque em consistência e padronização em todas as áreas.

Nível 4-5 (Gerenciado/Otimizado)

Capacidades avançadas. Foque em melhoria contínua e inovação.

6. Solução de Problemas

Problemas de Banco de Dados

Problema: Erros de banco de dados ou corrupção

Solução: Delete o arquivo do banco de dados e reinicie a aplicação. O sistema recriará o banco de dados automaticamente.

Conflitos de Porta

Problema: Aplicação não inicia devido a conflitos de porta

Solução: Altere o número da porta no arquivo main.py ou pare outros serviços usando a mesma porta.

Dependências Ausentes

Problema: Erros de importação ou módulos ausentes

Solução: Execute pip install -r requirements.txt para instalar todos os pacotes necessários.

Progresso Não Salva

Problema: Progresso da avaliação é perdido

Solução: Certifique-se de completar aspectos totalmente antes de passar para o próximo. Use o botão "Salvar e Sair" se necessário.

Obtendo Suporte

Se você continuar enfrentando problemas:

  • Verifique o console do navegador para erros JavaScript
  • Revise os logs do servidor para problemas de backend
  • Certifique-se de que todas as dependências estão instaladas corretamente
  • Verifique as permissões do arquivo do banco de dados

7. Perguntas Frequentes

Posso retomar uma avaliação incompleta?

Sim, seu progresso é salvo automaticamente conforme você completa os aspectos. Você pode retornar a avaliações incompletas na lista de clientes ou avaliações.

Como exporto meus resultados?

Use o botão "Exportar" na página de resultados para baixar seus resultados de avaliação em um formato padrão.

O sistema é compatível com dispositivos móveis?

Sim, a interface é totalmente responsiva e otimizada para dispositivos desktop e móveis.

Posso comparar múltiplas avaliações?

Sim, você pode completar múltiplas avaliações para o mesmo cliente para acompanhar o progresso ao longo do tempo e comparar resultados.

Quão precisas são as avaliações de maturidade?

A precisão depende de respostas honestas e completas. O sistema fornece orientação para cada pergunta para ajudar a garantir avaliação consistente.

Posso personalizar as perguntas da avaliação?

Sim, você pode modificar perguntas editando os arquivos de dados e reiniciando a aplicação. Veja a documentação técnica para detalhes.
