1. Introduction

What is SOC CMM?

The Security Operations Center Capability Maturity Model (SOC CMM) is a comprehensive framework designed to assess and improve the maturity of Security Operations Centers across organizations. It provides a structured approach to evaluating SOC capabilities and identifying areas for improvement.

Customer Management

Create and manage multiple customers/organizations

Step-by-Step Assessment

Guided questionnaire broken into manageable sections

Maturity Evaluation

5-level maturity scale assessment

Visual Results

Interactive radar charts and progress tracking

2. Getting Started

1

Customer Management

Navigate to the Customers page and click "Add Customer" to create a new organization. Fill in the customer details including name, email, and organization.

Tip: You can create multiple customers to manage assessments for different organizations.
2

Create Assessment

From the customer list, click "New Assessment" to start a new evaluation. The system will create a new assessment and redirect you to the questionnaire.

3

Complete Assessment

Follow the guided process through all domains and aspects. Answer questions using the 5-level maturity scale and track your progress.

3. Assessment Workflow

Domain Selection

Start with the Business domain and work through each domain systematically. Use the progress bar and step indicator to track your position.

Aspect Selection

Within each domain, select specific aspects to evaluate. Each aspect contains related questions that assess different capabilities.

Answer Questions

Answer all questions in each aspect using the 5-level maturity scale. Complete all aspects in a domain before proceeding to the next.

View Results

After completing all domains, view your results including radar charts, domain scores, and detailed breakdowns.

Assessment Tips

  • Save Progress: Your progress is automatically saved as you complete aspects
  • Resume Later: You can return to incomplete assessments at any time
  • Review Answers: Use the "Back to Aspects" button to review and modify answers
  • Complete All: Ensure all questions in an aspect are answered before proceeding

5. Understanding Results

Radar Chart

The radar chart provides a visual representation of your SOC's maturity across all six domains. Each axis represents a domain, and the shape shows your relative strengths and areas for improvement.

How to Read:

  • Larger area: Higher overall maturity
  • Balanced shape: Even development across domains
  • Spikes: Areas of strength
  • Dips: Areas needing improvement

Domain Breakdown

Detailed scores for each domain show your maturity level and provide specific insights into your SOC's capabilities.

Aspect Details

Drill down into specific aspects within each domain to understand detailed performance and identify specific improvement opportunities.

Interpreting Your Results

Level 1-2 (Initial/Developing)

Focus on establishing basic processes and documentation. Prioritize foundational capabilities.

Level 3 (Defined)

Good foundation established. Focus on consistency and standardization across all areas.

Level 4-5 (Managed/Optimized)

Advanced capabilities. Focus on continuous improvement and innovation.

6. Troubleshooting

Database Issues

Problem: Database errors or corruption

Solution: Delete the database file and restart the application. The system will recreate the database automatically.

Port Conflicts

Problem: Application won't start due to port conflicts

Solution: Change the port number in the main.py file or stop other services using the same port.

Missing Dependencies

Problem: Import errors or missing modules

Solution: Run pip install -r requirements.txt to install all required packages.

Progress Not Saving

Problem: Assessment progress is lost

Solution: Ensure you complete aspects fully before moving to the next. Use the "Save & Exit" button if needed.

Getting Support

If you continue to experience issues:

  • Check the browser console for JavaScript errors
  • Review server logs for backend issues
  • Ensure all dependencies are properly installed
  • Verify database file permissions

7. Frequently Asked Questions

Can I resume an incomplete assessment?

Yes, your progress is automatically saved as you complete aspects. You can return to incomplete assessments from the customer or assessment list.

How do I export my results?

Use the "Export" button on the results page to download your assessment results in a standard format.

Is the system mobile-friendly?

Yes, the interface is fully responsive and optimized for both desktop and mobile devices.

Can I compare multiple assessments?

Yes, you can complete multiple assessments for the same customer to track progress over time and compare results.

How accurate are the maturity assessments?

The accuracy depends on honest and thorough responses. The system provides guidance for each question to help ensure consistent evaluation.

Can I customize the assessment questions?

Yes, you can modify questions by editing the data files and restarting the application. See the technical documentation for details.
